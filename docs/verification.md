# 검증 결과 — D 평면 복원 · 입구 가벽 제거

2026년 10월 6일. 사용자가 첨부한 D 평면을 기준으로 건물을 다시 제작했습니다. 54×54m 외곽, 16×16m 중정, 폭 4m 순환 회랑과 독립 전시실 8개를 반영했습니다. 입구 앞 가벽은 전부 제거했습니다. 현재 콘텐츠는 샘플이며 로컬 미리보기에서 확인할 수 있습니다.

## 공간과 원본

- 원본 D의 방 크기·배치·작품 위치와 대조했습니다. 전시실 높이는 모두 12m, 중정은 14m, 회랑은 4.2m입니다. 출입구는 폭 3.2m·높이 3.6m이고 입구에서 작품으로 바로 접근합니다.
- 실제 모델에서 곡선 구간을 포함한 1,721개 이동 구간에 각각 중심과 주변 6방향의 충돌 검사를 실행했습니다. 충돌은 0건이며, 여덟 입구에서 작품을 향한 시선도 모두 열려 있습니다. 정해진 카메라 이동 구간 검사이며 자유 보행이나 건축 시공 검증은 아닙니다.
- 최종 원본을 별도 Blender 프로세스에서 다시 열어 2048px 조명 이미지 10장의 포함 여부, 최초 카메라 위치, 가벽 부재를 확인했습니다. 부품별 편집 원본에는 독립 면 객체 209개가 있습니다.
- 벽의 최종 경계 크기는 모서리 둥글림에 따른 3mm 이내 허용차로 확인했습니다. 최대 차이는 약 2.41mm이고 천장 높이는 12m로 일치합니다.
- 중정 벽과 회랑 천장 가장자리에 겹쳐 있던 면 4개를 제거했습니다. 기존 표면 좌표와 조명 이미지를 유지하며, 웹 화면에서 보이던 검은 띠가 사라진 것을 확인했습니다.

도면은 `assets/design/revision-d-open/`, 원본·표면 배치도·조명 이미지는 `assets/source/revision-d-open/`에 있습니다. 검사 기록은 `docs/dimension-checks.json`, `docs/model-audit.json`, `docs/source-check.json`, `docs/model-report.json`입니다.

## 표면과 조명

전시실 8개·회랑·중정을 각각 표면 배치한 뒤 256px 시험과 2048px 최종 조명 계산을 진행했습니다. 계산 잡음을 줄인 이미지와 원본 이미지 모두 보관합니다. 웹에서는 데스크톱 2048px, 모바일 1024px WebP를 사용합니다.

계산된 조명을 건물에 직접 표시하여 조명이 중복 적용되지 않게 했습니다. 작품 이미지·영상은 건물 질감과 분리되어 교체할 수 있고, 원본 비율을 유지합니다. 가는 모서리와 근접 표면에는 웹용 조명 이미지의 해상도에 따른 한계가 있습니다.

## 관람 기능과 화면

설치된 Chrome에서 다음 동작을 확인했습니다. 자세한 기록은 `artifacts/browser-checks.json`에 있습니다.

- 실제 입체 캔버스 클릭, 여덟 작품 선택·접근·미리보기·이전·다음, 선택 전 시점으로 복귀.
- 중정형 건물 배치도와 키보드 선택, 브라우저 뒤로가기, 작품 주소 직접 열기, 방향키·Escape, 연속 선택의 마지막 요청 반영.
- 영상 수동 재생과 작품 변경 시 정지, 이미지 로딩 실패 안내와 재시도, 움직임 감소 설정.
- 3D 표시 실패 시 프로젝트 내용을 유지하는 이미지 관람 모드. 처리되지 않은 브라우저 오류 없음.

1440×900, 390×844, 320×720에서 설명과 닫기·이전·다음 버튼을 검사했습니다. 페이지 가로 넘침이나 버튼 잘림은 발견되지 않았습니다. 좁은 화면의 작품 목록은 가로로 넘겨봅니다. 모바일 검사는 데스크톱 Chrome에서 화면 크기를 바꾼 결과이며 실제 휴대전화 검사는 아닙니다.

완성된 첫 화면은 `artifacts/production-1440.png`, `artifacts/production-390.png`에 있습니다. 작품 상세 화면은 `artifacts/verified-room-1.png`부터 `verified-room-8.png`까지 보관했습니다.

## 카메라 이동 보정

가장 가까운 회랑 지점 두 개로만 진입하던 연결 방식을 수정했습니다. 열린 중정에서 바로 보이는 지점도 이용하고, 불필요한 우회를 제거한 다음 모퉁이를 부드럽게 연결합니다. 중정에서 1번 방까지 이동 거리는 약 57.7m에서 33.6m로 줄었습니다.

작품 관람 높이는 데스크톱과 모바일 모두 2.3m이며 중정 첫 시점은 기존 2.6m입니다. 전시실 사이에서 높이가 출렁이지 않습니다. 이동 방향과 작품을 보는 방향을 분리하여 시선이 카메라를 통과하며 뒤집히던 문제를 없앴습니다. 도착 시 작품을 올려다보는 각도로 자연스럽게 맞춥니다. 복귀는 필요할 때 뒤로 물러나는 방식으로 불필요한 두 번의 방향 전환을 줄입니다.

큰 거리를 짧은 시간에 통과하던 기존 속도 대신 거리와 회전량에 따라 시간을 배분합니다. 화면 크기 변화는 구도만 맞추며 이동을 다시 시작하지 않습니다. 기록한 대표 동작은 중정→1번, 1번→2번, 2번→중정입니다. 전후 위치·회전 기록은 `artifacts/camera-motion-before.json`, `artifacts/camera-motion-after.json`에 있습니다.
