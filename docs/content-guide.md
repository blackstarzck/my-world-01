# 내 작업으로 교체하기

공간은 그대로 두고 **소개와 프로젝트 자료만 바꿀 수 있습니다.** 현재 모든 콘텐츠는 샘플이며, 연락처는 비워 두었습니다.

## 소개와 연락처

`src/data/projects.ts`의 마지막 소개 항목에서 이름, 짧은 소개, 상세 소개와 이메일을 바꿉니다. 이메일을 넣으면 소개 창에 연락 링크가 나타납니다. 페이지 제목과 검색 결과 설명은 `index.html`도 함께 수정합니다. 상단의 `still.` 글자도 본인의 이름으로 바꿀 수 있습니다.

## 프로젝트

같은 파일에 여덟 작품의 제목, 부제, 분야, 소개, 목적, 역할, 기간, 과정과 결과가 있습니다. 현재의 프로젝트 식별 주소를 유지하면 기존 공유 링크가 계속 작동합니다.

대표 이미지와 추가 이미지는 `public/art/`에 넣습니다. 권장 형식은 WebP이며 JPEG·PNG도 가능합니다. 큰 원본은 별도 보관하고 웹에는 폭 1200–1800px 정도부터 적용해 가까이 봤을 때의 선명도와 파일 용량을 확인하세요. 저해상도 목록용 이미지도 함께 교체합니다. 이미지 비율은 공간 안에서 자동으로 유지됩니다.

현재 각 프로젝트에는 대표 이미지와 구성 연구 이미지가 들어 있습니다. `media` 목록에 이미지 또는 영상을 추가할 수 있습니다. 각 항목에는 이미지인지 영상인지, 파일 주소와 내용을 설명하는 대체 문구를 넣습니다. 영상은 WebM 또는 브라우저가 지원하는 MP4를 사용합니다. 자동 재생은 하지 않으며, 다른 작품으로 이동하면 정지합니다.

프로젝트 외부 링크는 `links` 목록에 표시할 이름과 주소를 넣으면 나타납니다. 실제 자료로 교체한 뒤 `SAMPLE PROJECT`, 샘플 안내 및 소개의 샘플 문구를 함께 바꾸세요. 현재는 허구의 외부 링크나 이메일을 표시하지 않습니다.

## 공간을 바꿀 때

작품과 출입구 위치, 전시실 치수는 `assets/design/revision-d/drawing-dimensions.json`이 기준입니다. 현재는 여기서 입구 가벽을 제거한 D-open 안을 사용합니다. 승인된 배치를 바꾸려면 도면을 먼저 수정하고 제작 과정을 다시 실행합니다. `src/data/layout.json`은 도면에서 생성되는 파일이므로 직접 수정하지 않는 편이 안전합니다.

현재 건물은 중앙 중정과 순환 회랑으로 연결된 여덟 개의 독립 전시실입니다. 전시실 높이는 12m, 중정은 14m이며 입구 앞 가벽은 없습니다. 공간이나 작품 몸체를 옮기면 Blender 모델과 조명도 다시 만들어야 합니다. **이미지와 설명만 교체할 때는 다시 모델링하거나 베이킹할 필요가 없습니다.** 전시대와 입구 위의 작은 작품 이름은 모델에 포함되어 있으므로, 그 표기까지 바꾸려면 모델과 해당 구역의 조명 이미지를 갱신합니다. 원본은 `assets/source/revision-d-open/`에 있습니다.

## 공개 전 확인

실제 이름·소개·이메일, 여덟 작품의 자료·저작권·링크, 샘플 문구 제거, 영상 용량, 모바일 글자와 버튼을 확인합니다. `npm run build`로 만든 `dist` 폴더를 정적 웹 호스팅에 올릴 수 있습니다.
