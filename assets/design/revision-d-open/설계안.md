# D 평면 복원 · 입구 가벽 제거

사용자가 첨부한 D 도면을 현재 제작 기준으로 복원했습니다. 원본 도면의 건물 외곽, 방 크기·위치, 작품·출입구 위치를 유지하고 모든 전시실의 입구 앞 가벽을 제거했습니다.

- 건물 외곽 54×54m, 중앙 중정 16×16m, 순환 회랑 폭 4m.
- 전시실 8개, 각 방 높이 12m, 중정 높이 14m, 회랑 높이 4.2m.
- 출입구 폭 3.2m·높이 3.6m. 입구에서 작품 쪽으로 바로 접근합니다.
- 작품 예시 4.5×6m, 바닥에서 아래 끝 0.65m. 받침대 6×1.6×0.45m.
- 각 방은 작품 하나를 위한 공간이고, 중정에는 작품을 전시하지 않습니다.

`01-building-plan.svg/png`와 `02-building-section.svg/png`는 같은 치수에 기반합니다. `drawing-dimensions.json`의 가벽 항목은 제거 상태를 나타냅니다. 원본 D 도면은 상위의 `revision-d`에 그대로 있습니다.

웹 첫 화면은 중정을 보여주며, 작품 선택 시 열린 입구를 통과해 각 전시실로 이동합니다. 원본 이미지 비율은 늘리지 않고 유지합니다. 실제 시공용 구조 도면이 아닌 가상 전시관 제작 자료입니다.
